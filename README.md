# Burn Book

A World of Warcraft addon for the WoW Forever client: remember the players you meet, with friends, grudges and notes on each character.

This repository only hosts releases. Download the latest zip from [Releases](../../releases) and unzip it into `Interface/AddOns/`, or install it with an addon manager that reads GitHub releases (CurseBreaker: `install gh:rabbitXIII/BurnBook`).
